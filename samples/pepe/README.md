### Pepe Integration Sample

This is an example of integration with the Pepe festive greeting system. It uses auxiliary plug-ins that extend the agent's capabilities by adding standard interaction tasks for New Year celebrations, to which skills are applied that implement festive message generation and frog-themed congratulations.

### Environments

To set up and run the example, use the following environment variables. They are necessary for
proper connection to external suppliers/consumers.

```properties
export SIDUS_AI_CORE_PATH="SIDUS_AI_CORE_PATH"
```
