### Garland integration sample

Garland is a plugin for managing garlands and lighting effects. It creates various animated lighting modes, from classic running lights to complex dynamic patterns. The plugin is designed for controlling LED garlands, light panels, or any other lighting devices that support software control.

Key features:
Multiple lighting effects and animations
Adjustable effect speed
Asynchronous and synchronous operating modes
Real-time dynamic mode control
Support for smooth transitions and complex lighting patterns

### Environments

To set up and run the example, use the following environment variables. They are necessary for
proper connection to external suppliers/consumers.

```properties
export SIDUS_AI_CORE_PATH="SIDUS_AI_CORE_PATH"
```
